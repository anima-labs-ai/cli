Usage: anima agent|identity [options] [command]

Manage agents

Options:
  -h, --help             display help for command

Commands:
  create [options]       Create an agent
  list [options]         List agents. Defaults to all orgs you belong to; pass
                         --org or set a default with `am org switch` to filter.
  use <id>               Set the default agent for subsequent commands
  get [options]          Get an agent by ID
  update [options]       Update an agent
  delete [options]       Delete an agent
  rotate-key [options]   Rotate an agent's API key
  did [options]          Get the DID document for an agent
  credentials [options]  List verifiable credentials for an agent
  card [options]         Get the public agent card
  help [command]         display help for command
