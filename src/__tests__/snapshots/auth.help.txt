Usage: anima auth [options] [command]

Authentication and session management

Options:
  -h, --help         display help for command

Commands:
  login [options]    Authenticate with Anima — browser-based OAuth by default;
                     pass --api-key for non-interactive use
  logout             Clear stored authentication credentials
  whoami             Display current authentication status
  elevate [options]  Get temporary admin access, using this machine or a code
                     emailed to the owner
  help [command]     display help for command
